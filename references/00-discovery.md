# 阶段 0：赛道发现——候选种子词从生态数据里来

> 铁律：种子词从数据里来，不从经验里来。工具需求形态随时代演化（当前 AI 类在线工具是增量主力），本阶段目标是**找到候选词**，规模验证留给阶段 1-3。

## 0.1 发现入口（按性价比排序）

| 入口 | 方法 | 产出 |
|---|---|---|
| 5118 行业词库/流量词库 | 按行业浏览站内词库榜单 | 各行业高流量词 |
| 5118 每日新词/关键词动态趋势 | 看新出现的热词 | ⚡ 新兴需求（AI 类新词先出现在这里） |

| 百度 sugrec 生态种子 | `mine_sugrec.py` 跑「ai工具/在线工具/神器/办公」类**需求域种子** | 联想词即候选工具词 |
| 百度相关搜索 | SERP 右侧相关搜索（bsk 抓取） | 补充候选 |

## 0.2 生态种子词（发现轮输入）

发现轮种子描述「需求域」而非具体工具，让联想替我们枚举：

- 总域：ai工具 / 在线工具 / 神器 / 实用工具 / 效率工具
- 场景域：办公 / 学习 / 自媒体 / 设计 / 视频
- 人群域：学生 / 打工人 / 自由职业

## 0.3 提炼与迭代

1. 联想/相关搜索短语三分类：**具体工具词**（→候选清单）、**修饰词**（→标题素材）、**新线索词**（→下一轮发现种子）
2. 滚雪球至少 2 轮，直到一轮无新工具词出现；工作区按 `r1/ r2/` 保留轨迹
3. 时代校验：AI 类/在线化词标 ⚡；存量本地软件类词（下载安装类）单独标记「存量赛道」，与新兴赛道分开评估

## 0.4 输出

`00_discovery/candidates.csv`：candidate_word, source(哪个入口), category(⚡新兴/存量), notes → 作为阶段 1 挖掘的种子词输入。
