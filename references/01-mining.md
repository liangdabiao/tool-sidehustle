# 阶段 1：需求挖掘

目标：把「用户在搜索引擎里怎么表达工具需求」尽可能一网打尽。产出：长尾词原始词库（CSV：word, source, scraped_at）。

## 1.1 三种词根挖掘策略

### 策略 A：「在线」前缀

PC 端用户搜小工具的习惯是加「在线」。但直接拿「在线」拓展会混入「XX电视剧在线观看」等噪声，所以要**限定处理对象**。

主词根组合表（原文验证过）：

| 主词 | 工具类词缀 | 对象词缀 | 平台词缀 | 行业词缀 | 快速词缀 |
|---|---|---|---|---|---|
| 在线 | 工具 / 软件 / 程序 | 图片 / 照片 / 文本 / 音频 / 视频 / 语音 / 文章 | 抖音 / 微博 / 贴吧 / 知乎 / 闲鱼 / 小红书 | seo / sem / 社群 / 自媒体 | 批量 / 自动 / 快速 / 一键 / 极速 |

- 「在线 + 图片」→ 在线压缩图片；「在线 + seo」→ seo在线伪原创工具；「在线 + 抖音」→ 在线短视频去水印。
- 每一列都可以继续延伸（对象不限于此，群/好友/通讯录/直播等也是"事物"）。

### 策略 B：「器」后缀

大量小工具以「XX器」命名（下载器、转换器、群发器、播放器）。关键词工具不支持单字查询，所以借用用户下载习惯词缀组合查询：**「器 下载」**。同类逻辑字眼：**插件、助手**。

实操：拿「器 下载」去 5118 挖掘 → 下载数据 → 分词统计词频 → 高频通用词缀（下载 495582 / 模拟器 112451 / 浏览器 88763 / 器 75332 / 免费 15431 / 下载安装 13679…）再与「器」组合，继续挖掘更多「XX器」需求。

### 策略 C：计算机操作词

工具的一切行为都脱离不了操作系统层面的动作。用户也常直接搜功能描述（抖音批量发送XXX、YouTube自动下载、一键修改、在线查询）。

操作词表（可与前两策略任意组合：在线修改 / 批量发送 / seo查询 / 下载插件）：

| | | | |
|---|---|---|---|
| 安装 | 断网 | 插入 | 发送 |
| 保存 | 联网 | 打开 | 接收 |
| 检索 | 上传 | 关闭 | 传输 |
| 查询 | 下载 | 修改 | 删除 |
| 查找 | 打包 | 解压 | |
| 搜索 | | | |

## 1.2 关联查询（递归拓展，核心算法）

问题：一次挖掘只能拿到部分长尾词（5118「汽车」返回若干条，但相关长尾词共 8500 万+；百度相关搜索只给几个）。

解法：**从长尾词中分词提取「新鲜词缀」，与主词组合成新查询，循环到队列为空**。

伪代码（原文）：

```python
api = 'https://www.xxx.com/word/%s'   # 关键词拓展接口
word_queue = queue.Queue()            # 搜索词队列
key_seen = set()                      # 历史词缀
word_queue.put('汽车')                 # 起始主词

while not word_queue.empty():
    word_now = word_queue.get()
    new_word_list = get_word(api % word_now)
    for word in new_word_list:
        key_list = split_word(word)
        for key in key_list:
            if key == '汽车': continue        # 跳过主词
            if key in key_seen: continue      # 跳过已见词缀
            word_queue.put('%s %s' % ('汽车', key))   # 主词+新词缀 组合入队
            key_seen.add(key)
```

例：主词「汽车」→ 长尾词「二手汽车报价」→ 新词缀「二手」「报价」→ 队列加入「汽车 二手」「汽车 报价」→ 又挖出「二手汽车车行电话」→ 新词缀「车行」「电话」→ …直到队列为空。

放大器：起始队列加入大量行业大词（小说、电影、seo、自媒体…）；多引擎（百度/搜狗/神马/360）轮询 → 不间断挖掘出词库级数据。这是第三方关键词工具的挖词策略之一。

## 1.3 数据源与自动化（已验证）

| 数据源 | 方式 | 登录 | 说明 |
|---|---|---|---|
| 百度下拉词 | GET `https://www.baidu.com/sugrec?prod=pc&wd=<词>` | 免登录 | 返回 JSON `g[].q`，最稳定的程序化挖掘入口；需带常规 UA |
| 百度相关搜索 | SERP 页右侧「相关搜索」块（bsk 抓取） | 免登录 | 有「换一换」，可多轮取词 |
| 百度 SERP HTML | 脚本请求（注意反爬，低频 + UA 伪装；失败则走 bsk 浏览器） | 免登录 | 提取竞价/自然排名用于阶段 3 |
| 5118 网页版挖长尾词 | bsk：`https://www.5118.com` → 关键词挖掘 → 输入「在线 工具」点「挖词」 | 未登录可看；导出/复制需付费特权 | 输入框 CSS：`input[placeholder*='搜索']`，按钮文案「搜 索」；结果页标题「XX 长尾关键词挖掘」，显示总条数 |
| 5118 API | POST `https://apis.5118.com/keyword/word`（长尾词）、`/weight`（权重）、`/keywordparam`（搜索量），json | **需要 5118 API Key（付费）** | 长尾词单次最大 5000 条。批量挖掘首选；没有 key 时向用户索要 |

挖词脚本模板见 `scripts/mine_sugrec.py`（免登录 BFS 关联查询，含词频统计）。

执行要点：
1. 先和用户确定方向（行业大词 or 直接从「在线 工具」类词根开始）。
2. 阶段 1 只求全不求精，噪声留给阶段 2 清洗。
3. 每个词记录来源（哪个引擎哪个接口），便于回溯与补挖。
